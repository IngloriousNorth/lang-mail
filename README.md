# White-Paper Summary
There is a debate in neurolinguistics about whether human Language Processing is encapsulated, as in Chomsky's discrete Universal syntax, or whether it is an augmentation of fundamental cognitive functions (Morten Christiansen). My AI Architecture takes the following stance:
```
"We're arguing that language has changed over time to fit the human brain, not the reverse" -- Morten Christiansen
```
